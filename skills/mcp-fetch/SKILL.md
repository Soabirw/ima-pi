# Fetch MCP
Use Fetch for an exact URL and lightweight retrieval. Discover its configured tool through mcp. Request bounded content, then use supported continuation or truncation controls when necessary. Raw mode is only for cases where rendered text is insufficient. Summarize protected material rather than reproducing it extensively. Use Tavily for broad research.
