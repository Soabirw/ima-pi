# Taskwarrior CLI
Use the native task CLI with default user configuration, contexts, and structured task export JSON. Do not invent an SDK or MCP wrapper. Read before write and narrow automation by project plus UUID. Before annotate, tag, modify, complete, or delete, ensure exactly one intended task matches. Never perform broad writes or mark a lifecycle task done during an intermediate phase.
