# Qdrant MCP
Use Qdrant for durable standards, PRDs, architecture documentation, research, and reusable patterns. Do not use it for temporary task state or preferences. Discover advertised qdrant_find and qdrant_store tools through mcp. Search before an approved store, and keep collections and endpoints external. Stores require explicit authority. Never store credentials, private endpoints, raw traces, or transient logs.
