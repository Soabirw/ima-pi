# Chrome DevTools MCP
Use Chrome DevTools for live browser evidence, not static source inference. Discover tools through mcp, select the intended page, and use the latest accessibility snapshot before UID interaction. Inspect console and network evidence; use screenshots, emulation, Lighthouse, performance traces, and heap investigation when relevant. Captured visual artifacts still route through the configured vision-handoff policy.
