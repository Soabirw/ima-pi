# ima-pi

Pi-native IMA agent harness. Preserve ima-goose capabilities by outcome, not by copying Goose internals.

- Simple over complex; native Pi primitives before custom frameworks.
- Do not modify or retire ima-goose or ima-claude from this repository.
- Use Node 24+, ESM, pure functions, and the built-in Node test runner.
- Run `npm test` and `git diff --check` before handoff.
