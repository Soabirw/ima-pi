# FNR-3012 — dedicated vision-model routing and handoff

## Scope

This bounded technical probe provides `/ima:vision-probe <provider>/<model> <absolute-image-path>`. It sends exactly one accessible local PNG, JPEG, WebP, or GIF to the explicitly selected, authenticated Pi model only when its metadata advertises `image` input. It is not production orchestration.

The probe uses Pi's public `AgentSession.prompt(brief, { images, expandPromptTemplates: false })` interface and creates a temporary child session with `noTools: "all"` and an empty tool allowlist. The child returns one schema-version-1 JSON visual-evidence response. The parent validates requested/actual model, session, opaque image identity and basename, observations, limitations, uncertainty, and evidence-only scope. There are no fallbacks, retries, URL inputs, attachment forwarding, OCR guarantees, or lifecycle decisions.

## Privacy and failures

The optional absolute `IMA_PI_VISION_RESULT` destination receives sanitized JSON only: no bytes, full image path, prompt, raw response, transcript, credentials, or provider payload. Local image input is limited to 20 MiB before allocation; an oversized source fails with `image_too_large`. Stable failures include invalid arguments, local image errors, model/auth/capability errors, child/session failures, response/schema/identity failures, and result-write failure. User image paths are never changed or deleted.

The sanitized result is not the only possible retention: Pi may retain the prompt and image attachment in the generated temporary child-session file after command completion. The returned session path is acceptance evidence and this bounded probe does not automatically delete it. Use sensitive images only with that local retention understood; neither temporary-session retention nor provider-side handling is guaranteed ephemeral.

## Verification

```bash
node --test tests/vision.test.js
npm test
git diff --check
```

Tests are provider-free. Live acceptance remains a human/provider check:

```bash
IMA_PI_VISION_RESULT=/tmp/fnr-3012.json pi --no-session -e . -p "/ima:vision-probe <provider>/<vision-model> /absolute/path/to/image.png"
```

A passing live result requires useful evidence checked by a human against the source image. Authentication, capacity, provider rejection, timeout, or response noncompliance is reported honestly and never triggers substitution.
