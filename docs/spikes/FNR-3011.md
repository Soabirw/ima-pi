```bash

```

The child has only Pi's `bash` tool and must run exactly the same three status operations followed by one intentional mutation:


Child output is written only into a temporary controlled workspace. Serena and Qdrant remain read-only; no service SDK or storage dependency is added. The parent then independently runs `ima-mcp vestige search "<lifecycle key> <nonce>" --json`.

## Evidence and semantic completion

The child payload contains the lifecycle key, `FNR-3011`, an implementation-probe phase, an explicit completed outcome, and a per-run UUID nonce. Parent-side evaluation requires:

- successful parent and child gateway envelopes;
- exact requested and actual child provider/model identity;
- exactly four observed child commands, with only `smart_ingest` a mutation;
- a successfully processed ingest envelope; and
- at least one individual result from the high-level `vestige.search` `data.results` array containing the lifecycle key, Jira key, nonce, and completion/success language.

The evaluator ignores envelope/query metadata and never aggregates markers across results. Within a matching result it supports arbitrary nested physical representation, and explicitly ignores memory count, IDs, node type, create/update/supersede action, immutable version chains, and physical one-memory-per-phase assumptions. Structured result evidence is schema version 1 and contains only pass/fail checks, identities, command categories, semantic booleans, and stable errors. It excludes raw prompts, transcripts, command output, memory content, credentials, environment values, and provider responses.

Set `IMA_PI_GATEWAY_RESULT` to an **absolute** path to persist only this sanitized JSON result. Relative paths are ignored.

## Failure, cleanup, and limitations

The child prompt plus idle wait has one fixed 60-second deadline. On expiry the command returns the sanitized stable failure `child_execution_timeout` and disposes the child session. Stable failures also cover invalid arguments, unavailable/failed parent services, unavailable/authless child models, child execution or command drift, ingestion/recall failure, unverified semantic completion, and result-file write failure. A quota/auth/service/timeout/invalid-JSON/recall failure is an honest failed acceptance—there is no model fallback and no duplicate ingestion retry.

The temporary child workspace is preserved only by normal OS temporary-file lifecycle; the extension never deletes user paths or repository content. The one semantic Vestige update may be consolidated by Vestige and is not physically rolled back.
