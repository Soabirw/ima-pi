# FNR-3032 — MCP, browser, research, and work-management integration skills

## Approved outcome and source coverage

FNR-3032 ports ten integration skills into the Pi package: `mcp-serena`, `mcp-vestige`, `mcp-qdrant`, `mcp-atlassian`, `mcp-taskwarrior`, `mcp-context7`, `mcp-tavily`, `mcp-fetch`, `mcp-sequential-thinking`, and `mcp-chrome-devtools`. Source assets are the corresponding canonical `ima-goose/skills/` trees. `mcp-serena/scripts/migrate-context-to-serena.py`, `mcp-atlassian/scripts/atlassian-api.mjs`, and `mcp-taskwarrior/agents/openai.yaml` are retained as package support assets.

## Pi-native runtime

`extensions/mcp.ts` is a thin composition root around pinned `pi-mcp-adapter@2.17.0`, the latest release permitted by this repository's npm publication-age policy during implementation. `config/mcp.json` supplies lazy direct MCP defaults for Serena, Vestige, Qdrant, Context7, Tavily, Fetch, Sequential Thinking, and Chrome DevTools. The adapter loads its package config path while preserving shared user and project MCP configuration merge/override behavior.

Atlassian remains on the packaged REST helper; it is not a default MCP server. Taskwarrior remains on its native CLI; it is not an MCP server. `ima_context` retains its existing gateway boundaries. Formal `ima_lifecycle` persistence calls direct Vestige MCP `smart_ingest` and verifies receipt plus nonce, identity, phase, and outcome through `recall`; it does not require `ima-mcp`. This does not remove the separate `ima-mcp` paths used by context hydration or `/ima:cycle` reconciliation.

## Installation and updates

### Team or global installation

Install the package from the approved unpinned private Gitea source:

```bash
pi install ssh://git@gitea.theflccc.org:2222/IMA/ima-pi.git
```

This command was verified in an isolated Pi home on 2026-08-03: Pi exited successfully, recorded the package in its isolated settings, installed runtime dependencies, and exposed the package resources. Update explicitly with `pi update --extensions` or `pi update --all`; updates are never background or unattended.

### Local development

For a checkout used in local development:

```bash
pi install /home/eric/IMA/dev/ima-pi
npm run install:skills -- --validate
npm run install:skills
```

The installer copies package skills to `~/.agents/skills` by default. Use `node scripts/install.ts --dest <isolated-directory>` for validation. It preserves unrelated skills and atomically replaces only same-named package targets; it never edits Pi settings, MCP configuration, profiles, or credentials.

## Prerequisites and limits

Node 24+, Pi, `npx`, and `uvx` are required. Serena JetBrains navigation needs the Serena plugin and a running IDE. Vestige, Qdrant, Chrome, and their server executables/configuration remain external. `TAVILY_API_KEY` stays in the environment. Atlassian authentication stays in its existing environment variables. Missing executables or credentials should affect only the invoked lazy server.

Direct MCP skills use proxy discovery/calls; they do not claim generated SDK behavior. Direct Vestige ingestion does not replace the established lifecycle receipt protocol. No package config contains credentials.
